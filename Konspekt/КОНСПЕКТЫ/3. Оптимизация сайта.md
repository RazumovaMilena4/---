3. Оптимизация сайта

Оптимизация сайта - работа с кодом и текстом web-страниц, имеющая целью использование совокупности внутренних факторов, применяемых на странице web-сайта, оказывающих влияние на результат выдачи по данному поисковому запросу.

Продвижение сайтов - комплекс мероприятий, направленных на изменение внешних факторов, влияющих на результат выдачи по данному поисковому запросу или опосредованно связанных с поисковой выдачей.

Раскрутка сайтов - привлечение посетителей на сайт Заказчика способами, не связанными с результатами выдачи поисковых машин по данному запросу.

SEO - комплекс действий по внутренней и внешней оптимизации, направленных на повышение позиций сайта в поисковой виде.

Принципы поисковой оптимизации:
Факторы -> Релевантность (соответствие по чему-либо) -> Выдача

Факторы ранжирования - критерии оценки сайтов (в целом и их отдельных элементов), которые используют поисковые системы для того, чтобы формировать релевантную поисковую выдачу.

Релевантность страницы поисковому запросу - насколько страница сайта соответствует поисковому запросу, т. е. отвечает на вопрос, решает задачу, которая стоит перед пользователем.

Характеристики поисковых запросов:
По намерению:
- навигационные (ищет сайт)
- информационные (ищут информацию)
- коммерческие (товары или платные услуги)
- транзакционные (готовность к совершению действия)
- медиа (поиск фото, видео)
- неопределённые (не всегда можно определить, что хочет пользователь)
По частотности:
- высокочастотные (2-3 тыс и выше)
- среднечастотные (сотни до 2-3 тыс)
- низкочастотные (от 10 до 200-300)

ВЧ -> СЧ -> НЧ (Семантическое ядро)

По геозависимости:
С топонимом (с названием населённого пункта)
Без топонима

Структура, сформированная на основе семантики
1. Поисковые запросы
2. Структура сайта
3. Контент

Белое SEO - это использование методов, которые разрешены и одобрены поисковыми системами.
Чёрное SEO - использование запрещённых методов.

Клоакинг - сайт конструируется таким образом, чтобы поисковые роботы "видели" один контент (безобидный), а пользователи - другой (запрещённый)

Дорвеи - пользователи попадают сначала на одну страницу (с безобидным контентом), а оттуда идёт автоматическое перенаправление на страницу с запрещённым контентом

Внутренний поисковой спам - контент переполняется ключевыми словами в объёмах, которые превышают разумные пределы, за счёт чего искусственно поднимается релевантность.

Ссылочный спам - на сайт направляется большое количество ссылок со сторонних ресурсов.
Невидимый текст - текст, который не виден для пользователя

**Оптимизация северной части веб-приложений**
Производительность - количество обрабатываемых запросов в секунду (RPS) и скорость их выполнения (TTFB)
Устойчивость к отказам - способность системы при отказе или нескольких серверов к продолжению работы в рамках требуемых параметров.
Устойчивыми к катастрофам - системы, имеющие полное дублирующее резервирование и способные без сильной просадки работать при полном отказе одного из дата-центров.

Масштабируемость - пул возможностей для увеличения RPS
